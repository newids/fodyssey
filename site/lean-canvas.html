린 캔버스

기존 교육 인프라에 꽂는 AI 면역 엔진, 수료자를 지역 예방 조직으로 바꾸는 집단면역 네트워크 — 사업 모델을 9블록으로 요약했습니다. 모든 수치는 기관·기준 시점을 병기합니다.

①문제 Problem

  • 전화금융사기 피해 2025년 1–7월 누적 7,766억 원 (경찰청, 2025)
  • 피해액의 53%가 50대 이상 — 32%(2023) → 47%(2024) → 53%(2025년 1분기) (경찰청 국가수사본부, 연도별 발표 집계)
  • 수법은 생성형 AI로 주 단위 변형 — 대응은 1회성 지식 교육과 사후 차단 앱뿐. 진단·개인화·진단-학습 연결 전부 공백 (팀 자체 경쟁 서비스 조사, 2026-08-17)
  • 격차의 본질은 역량 — 취약계층 접근 96.5% vs 역량 65.6% (NIA 2024 디지털정보격차 실태조사)

기존 대안 — 공공 금융교육(콘텐츠·1회성) · 탐지차단 앱(단말·사후) · 기업용 모의훈련(조직 대상 한정)

④솔루션 Solution

  • 수법 인텔리전스 — 공개 수법 데이터를 AI가 훈련 시나리오로 자동 변환
  • 취약도 진단 — 훈련 행동의 Rule-based Scoring(재현·감사 가능) → 데이터 축적 후 ML 고도화
  • 적응형 훈련 + 조직화 — 취약 패턴별 집중 훈련(LLM+RAG). 훈련 수료자가 '금융안전 서포터'가 되어 이웃을 지키고, 서포터의 제보가 다시 훈련이 됩니다.

⑧핵심 지표 Key Metrics

  • 이수자 수 · 취약도 개선폭(사전·사후) · 서포터 배출 수 · 의심사례 제보 건수
  • 선례: 과기정통부·KISA 모의훈련(2026 상반기 630개사·25.5만 명). 재참여 우위 수치는 디도스 대응 훈련 지표 — 직접 비교하지 않음
  • 피해 감소액 추정치는 산출 근거 확보 전까지 미제시

③고유 가치 제안 UVP

금융백신 — 사기를 차단하는 앱은 많습니다. 사기에 속지 않는 사람을 만드는 인프라는 없습니다.

기존 교육 인프라에 꽂는 AI 면역 엔진, 수료자를 지역 예방 조직으로 바꾸는 집단면역 네트워크

차단은 항생제, 훈련은 백신입니다. 우리는 개인 접종(진단·훈련)에서 집단면역(조직화)까지 갑니다.

⑨경쟁 우위 Unfair Advantage

  • 데이터 플라이휠 — 훈련이 만드는 개인 단위 취약도 데이터(기존 피해 통계는 사후·집계) + 서포터 제보 환류. 훈련과 조직화를 하나의 데이터 루프로 묶은 사례는 조사 범위에서 관찰되지 않음 (팀 자체 조사, 2026-08-17)
  • 기존 인프라 위의 네트워크 — 실재하는 과정·캠퍼스망 위에 얹는 구조. 서포터·제보 이력은 후발 주자가 복제하기 어려움
  • 정책 정합: 금융위 생애주기별 금융교육('금융역량', 2025.12) · 포용금융 전략 추진단(2026.5~)

⑤채널 Channels

  • 기존 공공 교육 채널 탑재 — 서울시50플러스재단 캠퍼스 5개소·자치구 센터 14개소 → 서울런4050 → AI디지털배움터(전국망)
  • 금융기관 고객 교육·창구 연계 (파일럿 레퍼런스 확보 후)

②고객군 Customer Segments

  • 구매 1차 공공 교육 운영 기관 — 지자체·재단 (서울시50플러스재단 등)
  • 구매 2차 금융기관 — 은행·보험·증권 (고령 고객 보호 의무 대응)
  • 사용자 중장년·고령층 교육생 → 전 국민 (무료)
  • 얼리어답터 50플러스 북부캠퍼스 디지털금융교육 강사 양성과정 수료자 — 기수당 25명 (2026년 운영 확인)

⑦비용 구조 Cost Structure

  • 엔진 개발·운영 — LLM API 사용량·인프라
  • 시나리오 검수 — AI 1차 검증 + 사람 검수 (안전 설계)
  • 서포터 인증 체계 설계·운영 지원 — 활동비 재원은 기존 일자리 사업 틀 활용 제안 (재단 정책 판단 사항)

⑥수익 흐름 Revenue Streams

  • B2G 위탁·라이선스 — 기존 교육 사업의 성과 측정·고도화 (신규 예산이 아닌 사업 고도화 예산)
  • B2B 좌석 라이선스·API 과금 — 금융기관: 사고 예방 = 배상·상담 비용 절감, 보호 의무, ESG (지불 유인 논리만 확보 — 고객 검증 전)
  • 데이터 구독 — 익명화 지역·세그먼트별 취약도 인덱스 리포트
  • C(개인) 무료 · 금융상품 판매·중개 없음 · 단가·매출 추정치는 근거 확보 전까지 미제시
