# 핵심고객 정의서 (ICP: Ideal Customer Profile) — 금융백신 (FinVaccine, 가칭)

> 팀 Fodyssey (Fintech Odyssey) | 작성: 2026-08-22 | 기준: 전략 확정본 v1.0 · `가치제안_캔버스.md`(캔버스 A·B) · `docs/연계_교육프로그램_조사_50plus.md`
> **문서 지위**: 영업·연계 제안의 타깃 선정 기준. 본 문서의 고객 정의는 **공개 자료 기반 가설**이며 고객 인터뷰로 검증 전이다 (현실성 게이트 — §7 검증 계획 참조).

## 1. ICP 한 줄 정의

**"디지털·금융 교육 사업을 이미 운영 중이고, 성과 측정과 수료 후 관리가 과제로 남아 있으며, 중장년·고령층 접점 인프라(캠퍼스·센터·강사망)를 보유한 공공·준공공 교육 운영 기관."**

핵심은 세 조건의 동시 충족이다: ① 기존 교육 사업 실재 (우리는 신설이 아니라 고도화를 판다) ② 성과 측정 결핍 (핵심 페인) ③ 오프라인 접점 인프라 (조직화 네트워크의 토양).

## 2. 세그먼트 우선순위 (Tier)

| Tier | 세그먼트 | 대표 예 | 우선 이유 | 진입 경로 |
|---|---|---|---|---|
| **1** | 중장년 특화 공공 교육 재단 | **서울시50플러스재단** (캠퍼스 5·자치구 센터 14, 디지털금융교육 강사 양성과정 운영 확인) | ICP 3조건 전부 충족 + 강사 양성·일자리 사업까지 보유 — 조직화 프로그램의 완성형 토양 | 파일럿 제안 (북부캠퍼스 1개 기수) |
| 2 | 광역·기초지자체 평생교육·어르신 정책 부서 및 산하 기관 | 평생학습포털 운영 조직, 타 시도 중장년 재단(경기·부산 등) | Tier 1 성공 사례의 수평 복제 대상. 예산·인프라 구조 유사 | Tier 1 레퍼런스 확보 후 |
| 3 | 전국망 디지털 교육 사업 운영 주체 | AI디지털배움터 (과기정통부, 지역별 운영기관 위탁) | 전국 확산 단계의 채널. 위탁 구조라 지역 운영기관 단위 진입 | 2~3년차 |
| 4 | 금융기관 (은행·보험·증권) | 고령 고객 보호·ESG 담당 부서 | 수익성 최고이나 **지불 유인 논리만 확보 — 고객 검증 전.** 파일럿 데이터 없이는 진입 불가 | 파일럿 성과 데이터 확보 후 |

**이번 12개월의 ICP는 Tier 1 하나다.** Tier 2~4는 파이프라인이지 현재 타깃이 아니다 — 자원 분산 금지.

## 3. Tier 1 상세 프로필

### 3-1. 조직 특성 (Firmographics)

| 속성 | 기준 |
|---|---|
| 조직 유형 | 지자체 출연 재단·공공 교육 기관 (조례 근거, 시 예산 지원) |
| 사업 요건 | 디지털·금융 관련 교육 과정을 **현재 운영 중** (신규 개설 설득이 필요한 곳은 제외) |
| 인프라 요건 | 오프라인 교육 거점(캠퍼스·센터) + 강사망 또는 강사 양성 체계 |
| 부가 요건 (가점) | 중장년 일자리·사회공헌 활동 사업 보유 (서포터 활동비 재원 경로) |
| 규모 감각 | 기수 단위 교육 운영 (수십 명 단위 코호트) — 사전·사후 측정이 성립하는 최소 단위 |

### 3-2. 구매 트리거 (이 신호가 보이면 접촉한다)

1. 디지털·금융 교육 과정의 **신규 기수 모집 공고** (커리큘럼 개편 시점 = 탑재 제안 적기)
2. 기관 업무보고·의회 자료에 **성과 지표·사후 관리** 관련 지적 또는 계획 등장
3. 고령층 금융피해 예방 관련 **정책 이행 과제** 부여 (금융위 생애주기별 금융교육 방향, 2025.12 이후 지자체 확산 국면)
4. 강사 양성과정 수료 기수 배출 직후 (수료자 활용처가 필요한 시점 — 서포터 전환 제안 적기)

### 3-3. 의사결정 구조 (추정 — 인터뷰로 검증 필요)

```
실무 담당자(과장·PM) ── 발굴·검토 ──▶ 팀장·본부장 ── 승인 ──▶ 기관장
                                          │
                              시 소관부서 (예산·정책 정합 협의)
```

- **챔피언**: 교육 사업 실무 담당자 — 성과 보고 부담을 직접 지는 사람
- **경제적 구매자**: 본부장·기관장 — 기존 예산 내 집행 가능 여부가 관건
- **비토권**: 시 소관부서 — 정책 정합·감사 리스크 관점. **공무원 어필 3요소(정책 근거·측정 가능 KPI·기존 예산 프레임)가 여기를 통과시키는 열쇠**

### 3-4. 페인·성공 기준 (VPC 캔버스 A와 연동 — `가치제안_캔버스.md`)

- 페인: "몇 명 수강" 외 지표 부재 / 교안 갱신 여력 없음 / 수료 후 단절 / 신규 사업 부담
- 성공 기준 (고객이 성공이라 부를 상태): 기수 종료 시 **사전·사후 취약도 개선폭 리포트**가 자동으로 나오고, 수료자 일부가 서포터로 활동을 시작하며, 이를 업무보고 1쪽으로 옮길 수 있는 상태

## 4. 바이어 페르소나 (Tier 1)

| | P1. 실무 담당자 (챔피언) | P2. 본부장·소관 공무원 (승인자) |
|---|---|---|
| 하루의 관심 | 기수 운영·강사 섭외·만족도 조사, 상부 보고 자료 | 예산 집행 정합성, 의회·감사 대응, 정책 성과 |
| 우리에게 묻는 것 | "기존 커리큘럼을 얼마나 바꿔야 하나? 강사가 쓸 수 있나?" | "예산 항목이 뭐고, 근거 정책이 뭔가? 사고 나면 누가 책임지나?" |
| 설득 재료 | 강사 교육 2시간 + 기존 과정 탑재형 설계, 대시보드 리포트 샘플 | 정책 근거(금융위 생애주기별 금융교육·포용금융), KPI 4종, 기존 사업 고도화 프레임, 가상 환경·실계좌 무접근(안전 설계) |
| 실패 지뢰 | 강사 부담 증가로 인식되는 것 | 신규 예산 요구로 읽히는 것, 개인 금융정보 수집 오해 |

사용자 페르소나(교육생·서포터)는 구매자가 아니므로 본 문서 범위 외 — `가치제안_캔버스.md` 캔버스 B 참조.

## 5. Anti-ICP (맞지 않는 고객 — 정중히 거른다)

1. **교육 인프라가 없는 순수 콘텐츠 구매자** — 접점·강사망이 없으면 조직화 층이 성립하지 않아 차별화가 사라진다
2. **단발 행사·특강 수요** — 사전·사후 측정이 불가능한 1회성 요청 (우리가 대체하려는 바로 그 형태)
3. **B2C 유료화를 조건으로 거는 파트너** — 개인 무료 원칙과 충돌 (전략 §6 '버린 것')
4. **개인 금융정보 연동을 요구하는 수요** — 안전 설계 원칙(개인 금융정보 미수집) 위반
5. (초기 한정) **Tier 4 금융기관의 선행 도입 요구** — 파일럿 데이터 없이 진입하면 검증 부담이 역전된다

## 6. ICP 적합성 체크리스트 (영업·제안 전 통과 의무)

- [ ] 디지털·금융 교육 과정을 현재 운영 중인가?
- [ ] 오프라인 거점 + 강사망(또는 양성 체계)이 있는가?
- [ ] 기수 단위 코호트 운영인가 (사전·사후 측정 성립)?
- [ ] 기존 예산 프레임 안에서 집행 가능한 구조인가?
- [ ] 수료자 활용(일자리·활동 사업) 경로가 있는가? (가점)
- 4/5 미만이면 Tier 재분류 또는 보류. Anti-ICP 5항 중 1개라도 해당하면 제외.

## 7. 검증 계획 (현실성 게이트)

| 가설 | 검증 방법 | 시점 |
|---|---|---|
| §3-3 의사결정 구조 | Tier 1 실무 담당자 인터뷰 (파일럿 제안 과정에서) | 파일럿 제안 시 |
| §3-2 트리거의 실효성 | 기수 모집 공고 모니터링 → 접촉 전환율 기록 | 상시 |
| P2 승인자의 실제 관심사 | 재단 2026 업무보고 정독(백로그 기존 항목) + 제안 미팅 | 제안 전 |
| Tier 4 지불 의사 | 금융기관 인터뷰 — 파일럿 착수 후 | 파일럿 후 |

※ 본 문서의 기관 연계는 협약 체결 전의 제안이다. 특정 기관명은 공개 자료로 확인된 사실(운영 과정·인프라)의 인용이며, 해당 기관의 도입 의사와 무관하다.
