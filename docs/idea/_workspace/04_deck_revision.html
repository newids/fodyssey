04솔루션 심사기준 · 독창성

기존 교육 인프라에 꽂는 AI 면역 엔진, 수료자를 지역 예방 조직으로 바꾸는 집단면역 네트워크

차단은 항생제, 훈련은 백신입니다. 우리는 개인 접종(진단·훈련)에서 집단면역(조직화)까지 갑니다.
정체성

본체는 금융 소비자 보호 인프라 SaaS — 금융사·기관의 구매 대상이 되는 리스크 감축 자산입니다. 교육은 전달 채널이지 정체성이 아닙니다.

신규 교육 사업 신설이 아니라, 이미 시행 중인 교육 프로그램의 고도화 엔진입니다.

05면역 엔진 · AI 기술 구조 심사기준 · AI 기술 구조

AI가 아니면 수법 변형 속도를 따라갈 수 없습니다 — 지금 동작(Rule)과 고도화(ML·LLM)를 기능마다 나눠 씁니다.

기능 01

수법 인텔리전스

경찰청·금감원 공개 수법 데이터를 수집·정제 → AI가 훈련 시나리오로 자동 변환

지금(Rule) 공개 데이터 파이프라인 — 공공데이터포털 CSV 실재 확인 · 고도화(LLM) 변형 패턴 자동 생성

기능 02

취약도 진단

훈련 수행 행동 데이터를 Rule-based Scoring으로 점수화 — 기준·가중치 문서화로 재현·감사 가능

지금(Rule) 기준·가중치 기반 점수화 · 고도화(ML) 수행 데이터 학습으로 판정 정교화

기능 03

적응형 훈련

취약 패턴별(권위 순응형 / 악성앱·명의도용형 등) 집중 노출, 문해 수준별 문안 조정

지금(LLM) 취약 패턴·문해 수준 조건 전달 · 고도화(RAG) 공식 금융자료 근거 제시

AI 필연성: 생성형 AI로 변형되는 수법의 속도를 사람 손 교안 갱신이 따라갈 수 없습니다. 과장 없이, 학습 데이터가 필요 없는 규칙 경로부터 가동합니다.
06집단면역 네트워크 심사기준 · 독창성

훈련 수료자가 '금융안전 서포터'가 되어 이웃을 지키고, 서포터의 제보가 다시 훈련이 됩니다.

  1. STEP 01

    훈련 수료

    면역 엔진으로 진단·훈련을 마친 교육생

  2. STEP 02

    서포터 인증

    교육 이수 + 실습 통과 → 금융안전 서포터 인증

  3. STEP 03

    지역·가족 활동

    교육 보조 · 취약 이웃 동반 훈련 · 의심사례 상담 연결

  4. STEP 04

    제보

    현장에서 마주친 의심사례를 구조화해 제보

↺ 제보는 수법 인텔리전스로 환류되어 훈련 시나리오를 갱신합니다 — 사용자가 늘수록 훈련이 빨라지는 데이터 플라이휠.

활동비 재원은 신규 예산이 아니라 기존 일자리 사업 틀(가치동행일자리) 활용을 제안합니다. 서포터 활동의 지속성은 활동비·인정 체계에 달려 있어, 파일럿에서 검증할 리스크로 명시합니다.
