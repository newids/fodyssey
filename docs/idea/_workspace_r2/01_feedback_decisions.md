## 10. strategy-planner 인계 사항

1. **수용 16건 + 부분수용 14건**은 전부 `02_strategy_revision.md` v2.0 개정 대상이다. 보류 1건(A-4 플랫폼 수수료 모델)은 반영하지 않는다.
2. 개정 순서 권고: **§5 현실성 점검표 신규 행 등재(F-3) → §2 서비스 정의 재작성 → §3 연계·로드맵 재배치 → §9 정본 문안 C-9~C-12 신설 → §8-0 교차 대조 5문항 재수행**. 점검표를 먼저 채우지 않으면 산출물에 쓸 수 없는 문장이 본문에 먼저 생긴다.
3. **§8-0 자체 교차 대조는 이번 라운드에서 5문항 → 확장 필수**: 위 §9 충돌 점검 11항목을 대조 문항으로 흡수할 것.
4. 신규 문안 신설 시 **적용 범위 1줄 병기 의무**(CLAUDE.md §3 규칙 2) — C-9~C-12 전부 해당.
5. 검증 태스크 11건 중 **V-01·V-02·V-03은 전략 개정 전 회신이 필요**하다. 미회신 시 해당 요소는 §5 점검표에 "검증 상태: 미확인"으로 등재하고, 산출물에서는 한정 표기(조건부 서술)로만 사용한다 — 단정 금지.
