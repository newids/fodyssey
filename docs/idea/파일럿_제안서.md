# 파일럿 제안서 — 금융백신 (FinVaccine, 가칭)

> 팀 Fodyssey (Fintech Odyssey) | 작성: 2026-08-22 | 기준: 전략 확정본 v1.0 · `핵심고객_정의서.md`(Tier 1) · `docs/연계_교육프로그램_조사_50plus.md`
> **문서 지위**: Tier 1 기관 제안용 정본. 내부판은 서울시50플러스재단 북부캠퍼스(디지털금융교육 강사 양성과정)를 1순위 타깃으로 명시하며, 외부 게시판(`site/pilot.html`)은 기관 일반형으로 수위 조정. 본 제안은 협약 체결 전의 제안이다.

## 1. 제안 한 문단

귀 기관이 **이미 운영 중인 디지털·금융 교육 과정 1개 기수**에 금융백신 면역 엔진을 탑재해, 6개월 안에 세 가지를 증명하는 파일럿을 제안한다: ① 교육 성과를 **사전·사후 취약도 개선폭**으로 측정할 수 있다 ② 최신 사기 수법이 **자동으로 교안에 반영**된다 ③ 수료자가 **금융안전 서포터**로 전환되어 수료 후에도 성과가 이어진다. **파일럿 기수는 무상으로 제공한다** — 이후 단가는 파일럿 결과와 기관 예산 단위 확인 후 협의한다.

## 2. 파일럿 설계 (6개월)

| 단계 | 기간 | 내용 | 산출물 |
|---|---|---|---|
| 준비 | 4주 | 기존 커리큘럼 매핑(교체가 아니라 탑재), 강사 오리엔테이션 **2시간 1회**, 데이터 처리 방식 협의 | 탑재 계획서, 강사 가이드 |
| 사전 진단 | 기수 1회차 | 수강생 취약도 기준선 측정 (훈련 수행 행동 기반, 규칙 기반 산식 — 기준·가중치 문서 공개) | 기수 기준선 리포트 |
| 운영 | 기존 기수 일정 그대로 | 회차별 실전 모의훈련 모듈 제공 — 개인 취약 패턴별 문항, 최신 수법 자동 반영 | 회차별 참여·진행 데이터 |
| 사후 측정 | 기수 말 | 취약도 재측정, 개선폭 산출 | **사전·사후 개선폭 리포트 (업무보고 첨부용 1쪽 포함)** |
| 서포터 전환 | 수료 후 4주 | 희망 수료자 대상 서포터 인증(추가 실습) 및 활동 설계 — 교육 보조·이웃 동반 훈련·의심사례 제보 | 서포터 1기 명단·활동 계획 |

- 대상 규모: 1개 기수 (수십 명 단위 코호트 — 사전·사후 측정이 성립하는 최소 단위)
- 기존 과정의 시수·일정·강사진 변경 없음. 엔진은 기존 회차 안의 실습 모듈로 들어간다.

## 3. 기관이 얻는 것

1. **측정 가능한 성과**: "몇 명 수강"이 아니라 KPI 4종 — 이수자 수 · 취약도 개선폭(사전·사후) · 서포터 배출 수 · 의심사례 제보 건수 — 업무보고 1쪽 리포트로 제공
2. **교안 최신화 부담 해소**: 수법 인텔리전스가 최신 수법을 훈련 시나리오로 자동 변환
3. **수료 후 성과**: 서포터 활동이라는 사후 관리 스토리 (활동비 재원은 기관의 기존 일자리·활동 사업 틀 활용을 제안 — 기관 정책 판단 사항)
4. **정책 정합**: 금융위 생애주기별 금융교육('금융역량', 2025.12) · 포용금융 전략 추진단(2026.5~) 방향과 일치 — 근거 정책 명시 가능
5. 방법론 선례: 과기정통부·KISA 사이버 위기대응 모의훈련 (2026 상반기 630개사·25.5만 명 — 국가 집행 중인 사전 훈련 방법론)

## 4. 역할 분담

| 팀 Fodyssey가 한다 | 기관에 요청한다 |
|---|---|
| 엔진·훈련 모듈·대시보드 제공 및 운영 | 파일럿 기수 1개 지정 (기존 모집 그대로) |
| 강사 오리엔테이션(2시간)·운영 지원 | 강사 오리엔테이션 시간 1회 확보 |
| 사전·사후 측정과 리포트 작성 | 회차 내 실습 모듈 시간 배정 (기존 실습 시간 대체 가능) |
| 서포터 인증 체계 설계·운영 | 서포터 활동처 연결 검토 (기존 사업 틀 내) |

## 5. 안전·컴플라이언스 (사고 리스크 = 0 설계)

- **개인 금융정보를 수집하지 않는다.** 진단은 훈련 수행 행동 데이터만 사용
- **실계좌·실거래 무접근.** 모든 실습은 앱 안의 가상 상황 — 전화번호 0000 계열·가상 URL·가상 기관명만 사용
- **진단은 규칙 기반으로 출발** — 기준·가중치가 문서로 남아 재현·감사 가능 (금융위 AI 활용 7대 원칙 대응 설계)
- 데이터 처리 방식(보관 주체·기간·익명화)은 준비 단계에서 기관 기준에 맞춰 협의·문서화

## 6. 성공 기준과 다음 단계

- **성공 기준 (파일럿 종료 시 판정)**: ① 사전·사후 측정 완주율 ② 취약도 개선폭 유의미성 ③ 서포터 전환 인원 ④ 강사·수강생 만족(운영 부담 평가 포함) — 목표 수치는 기준선 측정 후 기관과 합의해 설정한다 (근거 없는 목표 선제시 안 함)
- 성공 시: 타 캠퍼스·센터 확산 협의 + 정식 단가 협의. 실패 시: 결과 리포트 전체를 기관에 남기고 종료 — 파일럿의 데이터는 기관 자산
