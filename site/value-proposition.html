가치 제안 캔버스

고객이 둘이므로 캔버스도 둘입니다 — 구매하는 기관(A)과 사용하는 사람(B). 두 캔버스의 접점이 사업의 성립 조건입니다.

Fit — 적합성 선언

차단은 항생제, 훈련은 백신입니다. 우리는 개인 접종(진단·훈련)에서 집단면역(조직화)까지 갑니다.

A의 핵심 고통(성과를 측정 못 하는 1회성 교육)과 B의 핵심 고통(내 취약점을 모른 채 남 얘기 같은 강의)은 같은 결핍 — 진단의 부재에서 나옵니다. 면역 엔진 하나가 두 고통을 동시에 해소합니다.

캔버스 A

구매 고객 — 공공 교육 운영 기관

재단·지자체 담당자와 공무원 의사결정권자. 서울시50플러스재단 등 — 기존 디지털·금융 교육 사업을 운영 중인 기관.

Value Map — 우리가 제공하는 것

제품·서비스Products & Services

  1. 면역 엔진 SaaS — 수법 인텔리전스(시나리오 자동 생성) · 취약도 진단(Rule-based, 재현·감사 가능) · 적응형 훈련(LLM+RAG)
  2. 기관 대시보드 — 기수·과정 단위 성과 리포트
  3. 서포터 인증 체계 — 수료자 조직화 운영 틀

고통 해결Pain Relievers

  1. 교안이 자동으로 갱신됩니다 — 최신 수법이 훈련 시나리오로 변환 P2
  2. "몇 명"이 아니라 "얼마나 개선"을 보고합니다 — 사전·사후 취약도 측정 P1
  3. 기존 커리큘럼에 탑재 — 신규 사업 신설이 필요 없습니다 P4
  4. 수료자가 서포터로 남아 사후 연결이 유지됩니다 P3

이익 창출Gain Creators

  1. KPI 4종(이수자 수 · 취약도 개선폭(사전·사후) · 서포터 배출 수 · 의심사례 제보 건수) 자동 집계 → 보고 자료화 G1
  2. 방법론 선례 인용 — 과기정통부·KISA 모의훈련(2026 상반기 630개사·25.5만 명, 국가 집행 중) G4
  3. 서포터 활동·제보 실적 = 지역사회 성과 스토리 G3
  4. 활동비 재원은 기존 일자리 사업 틀 활용 제안 (재단 정책 판단 사항) G2

Customer Profile — 기관의 현실

해야 할 일Customer Jobs

  1. 교육 사업 성과를 측정해 상부·의회·대외에 보고
  2. 고령층 금융피해 예방 정책 과제 이행 (금융위 생애주기별 금융교육 — '금융역량', 2025.12 / 포용금융 전략 추진단, 2026.5~)
  3. 한정된 예산 안에서 사업 고도화 + 수료 이후 사후 관리 설명

고통Pains

  1. 1회성 교육 — "몇 명 수강" 외에 보고할 지표가 없다
  2. 수법은 생성형 AI로 주 단위 변형되는데 교안 갱신 인력·예산이 없다
  3. 수료 후 교육생과의 연결이 끊긴다 — 사후 성과 부재
  4. 신규 사업 신설은 예산 확보·심의 부담이 크다

기대 이익Gains

  1. 측정 가능한 지표로 보고서를 쓸 수 있다
  2. 신규 예산 없이 기존 사업 고도화 프레임으로 성과
  3. 수료생의 지역 활동 — 조직화 성과 스토리
  4. 정책 방향과의 정합을 명시적으로 인용
캔버스 B

사용자 — 중장년 교육생 → 금융안전 서포터

기존 교육 과정의 수강생. 무료 사용자이자 집단면역 네트워크의 주체.

Value Map — 우리가 제공하는 것

제품·서비스Products & Services

  1. 실전 모의훈련 — 실계좌·실거래에 닿지 않는 가상 환경
  2. 개인 취약도 프로필 — 훈련 행동 데이터 기반 진단
  3. 서포터 인증·활동 연결 — 교육 보조 · 이웃 동반 훈련 · 의심사례 제보 채널

고통 해결Pain Relievers

  1. 최신 수법이 훈련에 자동 반영 — 배운 것이 낡지 않습니다 P1
  2. 진단이 먼저입니다 — 내 취약 패턴(예: 권위 순응형)별 집중 훈련 P2
  3. 서포터·제보 채널이 "물어볼 곳"이 됩니다 P3
  4. 수료가 끝이 아니라 서포터라는 다음 단계가 있습니다 P4

이익 창출Gain Creators

  1. 문해 수준에 맞춘 문안·큰글씨·단계별 안내 — 훈련 완주 경험 G2
  2. 취약도 개선폭을 본인이 확인 — 성장의 가시화 G1
  3. 훈련 수료자가 '금융안전 서포터'가 되어 이웃을 지키고, 서포터의 제보가 다시 훈련이 됩니다. G3·G4

Customer Profile — 교육생의 현실

해야 할 일Customer Jobs

  1. 의심스러운 전화·문자 앞에서 스스로 판단하고 대응 (기능적)
  2. 가족·이웃이 당하지 않게 지키기 (사회적)
  3. 배운 것을 살려 은퇴 후에도 역할과 활동 갖기 (사회적·정서적)

고통Pains

  1. 수법이 계속 바뀌어 배운 것이 금방 무력화된다 — 피해액의 53%가 50대 이상 (경찰청 국가수사본부, 2025년 1분기)
  2. 강의식 교육은 남 얘기 같다 — 내가 어떤 유형에 약한지 모른다
  3. 당할 뻔했을 때 바로 물어볼 곳이 없다
  4. 교육을 수료해도 그다음 역할이 없다

기대 이익Gains

  1. 내 취약 유형을 알고 집중 대비
  2. 안전한 환경에서 속아보는 실전 감각 — 사기 순간에 작동하는 판단
  3. "지키는 사람"이라는 역할과 인정
  4. 인증·활동으로 이어지는 참여 기회
